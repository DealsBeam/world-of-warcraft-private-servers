*One maintainer, checked daily around BlizzCon season.*

- **Wrong status, dead link, missing server?** Open an issue at [github.com/DealsBeam/world-of-warcraft-private-servers](https://github.com/DealsBeam/world-of-warcraft-private-servers) — fastest route, publicly tracked.
- **News tip?** Same place. Link the source (Discord announcement, forum post, datamine) and the date you saw it.
- **Takedown / correction request?** Same place, or via the repo. Server owners: this tracker lists public facts (names, statuses, dates) with links back. Ask and a listing is corrected or removed.

No newsletter, no accounts, no tracking beyond privacy-friendly page views. See [Privacy](/privacy/) and [Terms](/terms/).
