September 21, 2026: beta access now has a conduct edge. Blizzard customer support rep Vrakthris confirmed in a [forum post](https://us.forums.blizzard.com/en/wow/t/suspended-from-wow-forever-beta-without-any-reason-given/2354554/77) ([Icy Veins, PopTop](https://www.icy-veins.com/wow-forever/news/blizzard-bans-players-for-offensive-names-in-wow-forever-beta/)) that inappropriate or offensive character names can result in **removal of beta access**, ~~with an appeal path for errors~~.

## Official enforcement update (September 24)

WoW developer Fwoibles [confirmed an active enforcement wave](https://us.forums.blizzard.com/en/wow/t/2360739). Blizzard is issuing forced name changes and has removed beta access from some accounts whose names were "far outside" its Code of Conduct. The development team says each action was individually reviewed and Customer Service cannot assist with appeals for this enforcement wave. An automated naming-enforcement system is planned.

This first-party update supersedes the weaker September 21 support-rep report on appeals. It does not erase the earlier report; it narrows what players should expect when names trigger this specific action wave.

Three details matter. First, the trigger case was a suspension with no reason given; the reason (the offending name) had been emailed and landed in spam. Check spam before assuming a mistake. Second, the two-part name system widens the creative surface, and Blizzard knows it: "having the option for a first/last name provides opportunities for a lot of creativity, but our policies are still in place." Third, enforcement during beta sits primarily with QA and the development team rather than normal support channels.

Read with the realmless naming system on the [hub](/classic-plus/): region-unique two-part names were designed for community persistence, and this is the moderation cost of that design showing up in week one.
